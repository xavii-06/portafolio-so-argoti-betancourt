# Lista de Comandos básicos
## S.O. Windows con PoweShell
* lscpu
* cat /proc/cpuinfo
* free -h
* cat /proc/meminfo
* lsblk  
* lspci
* df -h
* lsusb
* sudo lshw -short

## S.O. Linux con Bash
* Get-CimInstance Win32_Processor
* Get-CimInstance Win32_PhysicalMemory
* Get-PhysicalDisk
* Get-Volume
* Get-PnpDevice -PresentOnly
* systeminfo   
* msinfo32
